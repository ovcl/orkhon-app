# Киоск горимоор ажиллуулах (Windows)

Апп киоск компьютер дээр **локал серверээр** ажиллана: `http://localhost:3000`. Интернэт шаардлагагүй, бүх зураг, панорам тухайн компьютерт хадгалагдана. Browser нь бүтэн дэлгэцээр, хаягийн мөргүйгээр нээгдэнэ.

## Киоск горимд юу өөрчлөгддөг вэ (`?kiosk=1`)

- **Идэвхгүй хугацаа:** 3 минут хэн ч хэрэглээгүй бол нүүр хуудас монгол хэлээр дахин ачаалагдана. Нээлттэй цонх болон тур бүгд хаагдана.
  - Хугацааг build хийхдээ `NEXT_PUBLIC_KIOSK_IDLE_SECONDS`-ээр өөрчилнө.
- **Гадаад холбоос:** вэб сайт, Google Maps, Quest зэрэг холбоосыг дарахад киоскоос гарахгүй. Оронд нь **QR код** гарч, хэрэглэгч утсаараа уншуулж нээнэ.
- **Хаалттай үйлдлүүд:**
  - хуудсыг томруулах (Ctrl+дугуй, Ctrl +/−, хоёр хуруугаар чимхэх);
  - баруун товчны цэс;
  - текст сонгох, зураг чирэх.
  - Газрын зураг болон панорамыг томруулах хэвийн ажиллана.
- **Нуусан товч:** "Офлайн хадгалах" товч. Киоскт бүх зүйл аль хэдийн локалд байгаа тул хэрэггүй.
- **Унтраах:** `?kiosk=0` хаягаар орвол киоск горим унтарна. Энэ тохиргоо тухайн browser-т хадгалагдана.

## Анхны суулгалт (нэг удаа)

1. **Node.js 20 LTS** (эсвэл шинэ хувилбар) суулгана: https://nodejs.org
2. Аппыг хуулна (`git clone https://github.com/ovcl/orkhon-app` эсвэл хавтсаар нь). Зам богино байвал зүгээр, жишээ нь `C:\orkhon-app`.
3. Тухайн хавтсанд:
   ```bash
   npm ci
   npm run build
   ```
   Build хэдэн минут үргэлжилнэ.
4. Туршиж үзэх: `kiosk\start-kiosk.bat`-ийг давхар дарна. Сервер асаж, Edge бүтэн дэлгэцээр нээгдэнэ.
5. Windows эхлэхэд автоматаар асдаг болгох:
   ```bash
   powershell -ExecutionPolicy Bypass -File kiosk\install-startup.ps1
   ```
   Болиулах бол `-Remove` нэмж ажиллуулна.

## Өдөр тутам

- **Асаах:** компьютер асаж хэрэглэгч нэвтрэхэд автоматаар асна. Гараар асаах бол `kiosk\start-kiosk.bat`.
- **Унтраах (ажилтан):**
  1. `Ctrl+Alt+Del` дарж Task Manager нээх, эсвэл `Alt+Tab` дарж өөр цонх руу шилжих.
  2. `kiosk\stop-kiosk.bat`-ийг ажиллуулах.
  - Browser-ийг `Alt+F4`-өөр хаавал 5–10 секундын дотор **автоматаар дахин нээгдэнэ**. Энэ нь зочин санамсаргүй хаахаас хамгаалдаг.
- **Лог:** `kiosk\logs\` (`kiosk.log`, `server.log`, `server.err.log`, `build.log`).

## Шинэчлэх

```bash
kiosk\stop-kiosk.bat
git pull
npm ci
npm run build
kiosk\start-kiosk.bat
```

## Windows-ийн зөвлөмж тохиргоо (гараар)

- **Тэжээл:** Settings → System → Power. Дэлгэц унтрах болон компьютер унтах хугацааг **Never** болгоно.
- **Автомат нэвтрэлт:** тусдаа "kiosk" хэрэглэгч үүсгээд автоматаар нэвтэрдэг болгоно (`netplwiz`).
- **Мэдэгдэл:** Settings → System → Notifications-ийг унтраана. Focus assist болон Do not disturb-ийг асаана.
- **Windows Update:** Active hours-ийг музейн ажлын цагаар тохируулна. Ингэвэл ажлын цагаар компьютер дахин асахгүй.
- **Илүү хатуу горим (заавал биш):** Settings → Accounts → Other users → *Set up a kiosk* (Assigned Access). Тухайн хэрэглэгч зөвхөн Edge-ийг ашиглах боломжтой болно.
  - Энэ горимд хаягаа `http://localhost:3000/?kiosk=1` гэж оруулна.
  - Серверийг тусад нь асаана: Task Scheduler-д "At startup" үед `start-kiosk.bat`.

## Скриптийн тохиргоо

```bash
kiosk\start-kiosk.bat -Port 3000 -Browser edge
```

- `-Browser` нь `auto`, `edge` эсвэл `chrome` байж болно.
- `-NoWatchdog` нэмбэл browser хаагдахад дахин нээхгүй.
